This works in Chromium browsers

@if (supported) {

Everything is saved straight into the folder you choose - your downloaded works, the index, any images, and the record of each run. Nothing is uploaded anywhere, and nothing is kept by this site.

Writing into a folder you picked needs the File System Access API, which Chrome, Edge, Brave, Opera and Arc have. Firefox and Safari do not, so downloading will not work there. Your browser supports it, so you are set.

} @else {

This browser cannot download. Saving into a folder you choose needs the File System Access API, and only Chromium browsers have it - Chrome, Edge, Brave, Opera or Arc. Firefox and Safari do not.

You can still open a folder and browse a library that is already there. Starting a run needs one of the browsers above.

}
