Saving to Dropbox, or to this device

Using Dropbox? You are all set.

A library in Dropbox works in any browser, on any device - phones and tablets included - and a run can carry on without this page, if you tick Run as background task when you start it.

Saving to a folder on this device needs three things

  • A computer, not a phone or tablet.
  • A Chromium browser - Chrome, Edge, Brave, Opera or Arc. Writing to a folder you pick needs the File System Access API, which Firefox and Safari do not have.
  • This page kept open for the whole run. The page does the saving, so closing it stops the run - and a large library can take hours.
@if (supported) {

This browser can save to a folder on this device.

} @else {

This browser cannot save to a folder on this device. Use Dropbox, or open this page in one of the browsers above on a computer. You can still open a folder here and browse a library that is already in it.

}

Either way, nothing is uploaded anywhere else, and nothing is kept by this site.
